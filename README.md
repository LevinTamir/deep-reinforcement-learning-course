# Deep Reinforcement Learning

This repository contains assignments for the **Deep Reinforcement Learning (364-2-1031)** course @ **BGU**.

## Create the environment
```bash
cd ~/PATH_TO_DIR/hw1/ # or hw2/hw3

conda env create -f hw1/drl_hw1_env.yaml # or hw2/hw3

```

After activating the environment, navigate to the folder containing the Python files and
run the wanted scripts.
